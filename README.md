# Hey, I'm Caelan

I run **Slugworth**, a solo IT and web shop in Westland, Michigan, serving Westland,
Canton, Plymouth, and Livonia. I am self-taught, and I build the tools I use to run
the business: self-hosted, one login, no subscriptions.

## Projects

- [slugworth-suite](https://github.com/slugworth95/slugworth-suite)
  Slugworth Suite: clients, proposals, invoices, and scheduling in one app (Express + SQLite or Postgres)
- [Ledger](https://github.com/slugworth95/Ledger)
  Installable notes PWA that exports every note as one self-contained .html file (vanilla JS, no build step)
- [Client-Tracker](https://github.com/slugworth95/Client-Tracker)
  Kanban client tracker with custom fields, follow-ups, notes, and CSV import/export (Express + SQLite or Postgres)
- [Proposal-Builder](https://github.com/slugworth95/Proposal-Builder)
  Proposal builder with live preview, product catalog, version history, and server-side PDFs (Express + SQLite)
- [Invoice-Generator](https://github.com/slugworth95/Invoice-Generator)
  Invoice generator with auto-numbering, status tracking, payment reminders, and server-side PDFs (Express + SQLite)
- [Scheduling-Tool](https://github.com/slugworth95/Scheduling-Tool)
  Scheduling tool with a weekly calendar, recurring appointments, availability windows, and email reminders (Express + SQLite)

The four small tools were merged into Slugworth Suite and stay online as reference.

## Stack

Vanilla JavaScript with no framework, Express, SQLite with an optional Postgres
adapter, pdfkit for server-side PDFs, Docker for self-hosting, and Cloudflare for
DNS and Pages.
